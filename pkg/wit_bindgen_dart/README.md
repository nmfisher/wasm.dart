## WIT bindgen for Dart

This (unpublished) crate is based on [wit-bindgen-core] and generates Dart code from
`.wit` interface definitions.

For an example of a complex package generated by this, see the [wasi package](../wasi).

This crate is compiled as a `cdylib` which [wasm_tools](../wasm_tools/) then
loads and runs to implement the `wasm_tools witgen` command.

[wit-bindgen-core]: https://crates.io/crates/wit-bindgen-core
